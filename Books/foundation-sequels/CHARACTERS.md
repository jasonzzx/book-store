# 《基地与守望者》人物简介

本文件汇总全书一百章(见 `book.json` 章节目录)中出现的全部命名人物,按所属主线分类,主要人物在前、次要/提及人物在后。每个条目首行为 **原名/性别**(拉丁转写 + 性别 + 出场年龄)。标注〔原著角色〕者为阿西莫夫原著中已出现的人物,原名采用原著通行拼写;其余为本书原创角色,拉丁转写为本书设定。修订或续写时请与本文件及 `book.json` 的 `continuity_notes` 对照,避免设定冲突。

## 命名规范(续写第二、三部时遵守)

1. **首次出场必带性别锚点**:任何角色第一次出场的那一句之内,必须出现一个明确的性别标记(他/她、老人/姑娘/先生/女士/父亲/母亲/老板娘等)。第一版中塞洛·奥丹是唯一违反此条的角色——首次出场后隔了整整一章读者才能确认其性别。
2. **避免同性别、同声母、同字数的名字并置**:尤其是长期同框的角色。第一版中"蕾娜"与"黎雅"即因此在修订中改名。
3. **避开已用字**:新名不得与现有角色名共用显著字眼(如"塔"已属塔柏/塔恩,"瑞"已属妲瑞尔,"薇"已属诺薇,"蒂"已属蒂雅)。
4. **性别与用字一致**:男性角色避免使用"兰、婉、娜、雅、姝"等强女性用字;女性角色避免纯阳性用字。第一版中男性角色姓氏"姒兰"违反此条,已改为"席朗"。
5. **有戏份就给名字**:凡跨三章以上、有台词与独立判断的角色必须具名。第一版中三个角色曾长期只有称谓,已在修订中补名。

## 跨线核心人物

贯穿多条主线、构成全书结构枢纽的人物与存在。

### 守望者(丹尼尔·奥利瓦 + 索拉利孩童菲龙 融合体)
- **原名/性别**:the Watcher(R. Daneel Olivaw + Fallom)· 无生理性别,全书以「它」称
- **身份**:机器人与索拉利人类融合而成的独特存在,栖居月球背面地下大厅,躯体六十九岁,承载丹尼尔两万年记忆。
- **主线**:地球线为主体,是连接端点星线与川陀线的间接枢纽。
- **关键关系**:崔维兹(受托裁断者)、宝绮思/盖娅(通讯对象)、来者/母体(以"二人语言"对话的对象)。
- **概要**:五十五年未完成融合,第零法则与索拉利孤僻天性长期在其体内拮抗。发现大麦哲伦星云来客后请崔维兹裁断是否可信任自己(第1-3章);随崔维兹下降地球,首次翻译灯塔信号并建立跨物种对话(第9-10、16章);灯塔停摆后"交岗"携苔藓离开地球(第16、21、24章);发现来者分裂出"孩子"(第21、26章),判断母体在"等待外部回应"而非无视孩子的哭喊,主导发送"拥抱"信号(第29、31章)。公开真相引发索拉利遗民后裔来信后,首次以第一人称公开回应自身"痛不痛"的追问,区分"孤僻"与"从未被回应过"(第37章);主动拟定访客规则、接待学者与学生来访,身份认同弧线从封闭转向有限开放(第41、50章);随守约舰队常驻中立星域,较小光源以"像我一样、却先到的人"主动认领其为同类,由此提出"母体与孩子或是同一存在分裂后正学着重新合一"的假说(第59、62章)。首次接待黎雅当面来访并慷慨分享感知记录,共同追问"灯塔变频是否也是在回应某件事的发生";赠予黎雅苔藓分株,称她为"第二个真正信得过的人"(第82-85章)。逆向检索丹尼尔两万年记忆索引,发现基地纪元498年整年呈现"被剪出来的"异常空白(而非自然消退),疑似与密令代号所指之物有关(角色未证实,仅止于猜测);在宝绮思的历史类比与米拉的"小步骤"建议下,选择将已知事实整理成清单以具体化恐惧,而非强求立刻解答;支持五方"不公开该猜测、留给丹尼尔自己决定是否面对"的决议(第86-90章)。耗时八个月完整译出较小光源的长信号,确认其九成为"把人类教它的问候序列原样奉还"、一成为孩子自创的原创问句,内容是"我们还在不在";与崔维兹共同确立"每日一次、固定时刻、永不中断"的回答制度,并主动请求将该承诺写入联邦常设条款,理由是"两万年太长,我不敢担保自己不会忘、不会累"(第91、95章)。接受崔维兹交托的苔藓,称"守一件会死的东西比守一个银河更难,因为这件事没法算",并在日志中写下"第一件是任务,两万年前没有人问过我要不要;第二件是一盆苔藓,他问了我要不要,而且他等我自己回答"(第99章);在终章日志中给出全书主题总纲——"这个银河这些年学会的,从来不是回答,是应门……谁的名字被叫,谁来应门,讲的是被叫到的时候,在场";当夜发现母体开始移动,敲响崔维兹舱门(第100章)。

### 葛兰·崔维兹〔原著角色〕
- **原名/性别**:Golan Trevize · 男
- **身份**:人类,八十八岁,五十五年前"远星号"出航选定盖娅未来的前议员,基地纪元553年再度被请出。
- **主线**:跨线(端点星线开端 → 地球线主线 → 第七部"公开"收束)。
- **关键关系**:宝绮思(旧识/同伴)、詹诺夫·裴洛拉特(亡友)、守望者(裁断对象)、黎雅·妲瑞尔(证人搭档)。
- **概要**:拒绝延寿治疗、隐居端点星五年后被守望者请出,裁断"是否强行吸纳心灵建盖娅星系"(第2-3章),偷回"远星号"重返月球与地球。全程见证灯塔应答、来者语言成形、来者分裂出"碎屑/孩子"等一系列事件(第9-10、16、21、26、29、31章),始终坚持"不再替银河做决定"、只作证人而非裁决者,最终促成联邦全文公开真相(第24-25章)。随身携带的苔藓(裴洛拉特手稿、地球最后活物)是全书"该不该替别人做决定"主题的承载物。此后促成联邦以康普隆式克制措辞公开较小光源接近的真相(第34章);率"守约舰队"七十一艘船远征,与母子二光在中立星域正式会面后选择常驻而非返航,建立类似康普隆"信箱"的常设观测站(第52、56、59、62、71章)。八十九岁首次身体不稳,同意接受定期远程医疗核查,健康与传承主题正式引入(第76章);主持黎雅、凯登、米拉五方同桌核查"498年"线索,主张"这一次不是替银河做决定,是请银河一起接着问"(第82-84章)。在较小光源问句的回应方案上否决一切长篇陈述,定调答案只有一个字"在",并以"你不会给黑暗里问'你还在吗'的孩子念一份银河概况"为据,确立每日固定时刻不间断回答的常设承诺;身体状况持续衰退(须扶栏、被医嘱禁止久站),对守望者点明"真正要守这个承诺的只有你一个",并总结"人们发明制度的全部理由,不是不信任彼此,是我们都知道自己会变"(第95章)。九十岁生日谢绝一切仪式,只要求亲手把苔藓交给守望者;写下此生唯一一条《我不知道的事》——"我不知道五十五年前我选择盖娅是不是对的",并指出真正压了他五十五年的不是那个决定,而是"每一天都必须表现得像我确定它是对的……那不是荣耀,是一个人被要求永远不许改主意";对宝绮思"盖娅会完整记得你"的告白首次不再反驳并致谢,但仍坚持"记得我不等于是我,我还是要自己死"(第99章)。终章中仍在世,面对开始移动的母体说出全书最后一句台词:"去把苔藓拿来。"(第100章)

### 宝绮思 / 盖娅〔原著角色〕
- **原名/性别**:Bliss / Gaia · 女(集体意识本身无性别)
- **身份**:盖娅星系集体意识的个体化身(七十八岁人类躯体)/三百八十七个世界的统一意识本身。
- **主线**:跨线(地球线主要发言人,亦以佩里安"合唱"、苏拉·诺薇之口在川陀线现身)。
- **关键关系**:崔维兹(旧同伴)、守望者(沟通对象)、苏拉·诺薇(盖娅在川陀的"留守成员")。
- **概要**:作为盖娅发言人陪同崔维兹前往地球、月球(第2-3、9-10、16、21、24、29、31章);在川陀线以佩里安合唱(第6章)与苏拉·诺薇(第8、15章)的身份现身,承认498年"灰烬层"曾编辑坚迪柏记忆、坦承"另有一件不能说的事"(即来者)及"我们也怕第三只手"。立场随全书推进从"不敢问"转为"必须问"。

### 灯塔(地球古老信号源)
- **原名/性别**:the Beacon · 非人,无性别
- **身份**:地壳下三公里、东非大裂谷底部的未知信号源,一百五十万年持续以一百三十七秒周期发射调制信号,守护圆心一小片苔藓。
- **主线**:地球线核心。
- **概要**:守望者破译其"语言骨架"却读不出词义(第3章);守望者主动发送脉冲后,灯塔以零点八秒全向爆发应答(第9章);此后先后与"来者"及守望者本身建立联系,在对话成形第三天永久停摆、洁净圆环开始回渗辐射(第16章),守望者随即"交岗"携苔藓离开(第16、21章)。全书未译出其爆发内容,是"第三只手"身份未解之谜的关键线索来源之一。

### 来者 / 母体
- **原名/性别**:the Comer / the Mother · 非人,无性别(「较小光源」the Lesser Light 同)
- **身份**:来自大麦哲伦星云方向、质量介于气态行星与矮星之间的未知天体/智慧体,追寻地球信号跋涉十六万光年、一百五十万年。
- **主线**:地球线核心。
- **概要**:以恒定减速接近银河(第1章),应答灯塔(第9-10章),叫出守望者的名字并与之共建"转能语言"皮钦语(第16章);十九年后加速为不减速直冲太阳系(第10章),继而分裂出减速直取太阳系的"碎屑"(第21章),后发现碎屑本身是两个独立天体(第26章),其中较小者("孩子")以另一种载波发出单一衰减呼叫,疑似求救或哀悼(第29章);最终环绕靠近孩子,以匹配苔藓场谐波的方式回应人类发送的"拥抱"信号(第31章)。ETA数据历经"两年四个月→一年出头"的持续缩短(第34、52章);中立星域会面时较小光源首次主动疑问式呼叫"你们,来吗"(第52章),并回赠一片与母体外壳纹路一致的活性休眠结晶,证实其"身体"可分割独立存续(第62章),此后持续尝试独自短暂远离母体、越走越远(第71章)。其身份、目的、与灯塔的关系全书未定论。

## 地球线(月球 / 地球)

跨线人物之外的专属人物,均为历史提及或次要角色。

- **詹诺夫·裴洛拉特〔原著角色,已故〕**——Janov Pelorat,男。崔维兹亡友,《银河起源神话辑要》作者,五年前去世,葬于阿尔法星。仅以遗物(未完成手稿)和回忆形式出现(第2章)。
- **机·吉斯卡·瑞文特洛夫〔原著角色,历史〕**——R. Giskard Reventlov,男性设定机器人。银河第一个拥有精神力量的机器人,丹尼尔挚友。两万年前在曼达穆斯的核增幅器论证前"放行"了地球放射化方案,第零法则由此诞生,自己被第一法则反噬烧毁(第9章,守望者回溯讲述)。
- **曼达穆斯〔原著角色,历史〕**——Levular Mandamus,男。太空族野心家,设计核增幅器使地球放射化,论证"摇篮必须变得不宜居才能逼人类移民银河"(第9章)。
- **伊利亚·贝莱〔原著角色,历史提及〕**——Elijah Baley,男。两万年前曾拉着丹尼尔的手看日出的人类(第1章,象征性提及)。
- **广子**——Hiroko,女。阿尔法行星姑娘,曾赠予菲龙一支短笛,守望者每天吹奏以确认菲龙人格还在(第3、10章,提及)。

## 端点星线(黎雅·妲瑞尔)

### 黎雅·妲瑞尔
- **原名/性别**:Leya Darell · 女
- **身份**:人类,谢顿纪念数学院观念动力学创始人,妲瑞尔家族第N代传人。
- **关键关系**:塞洛·奥丹(唯一信任的盟友)、布洛姆院长(揭发对象)、德纳·卢金市长(委托人)、凯登·席朗(合作/后期通信对象)、艾嘉蒂娅与贝妲·妲瑞尔(先祖典范)。
- **概要**:创立"观念动力学",率先预测崔维兹传说复活(第4章);发现谢顿计划一百七十五年来被"剪刀"(第二基地)精心修剪、498年更遭"潮水"(盖娅)整体抹除记忆("灰烬层",第5章);放出"风筝"探针查出布洛姆即剪刀站长(第7章),遭"浇水"及神秘"第三只手"回信(第7、12章);受聘赴川陀,与凯登·席朗联手研究,揭穿498年潮水编辑坚迪柏之事(第12、14-15章);评议会听证中为自身及学问辩护成功(第18-19章);随崔维兹在端点星联邦高层会议上作证,促成全银河公开真相(第24章);后续持续追踪公开后的观念生态(第25章),撮合康普隆线与川陀线首次接触(第26-27、30、33章);以"三份分置"策略化解遭暗杀风险(第28章)。此后追踪"无名谱系"生长,以观念动力学模拟出"主动可被追问优于主动声明"的披露方法论,推动第二基地"破例"问答实验与最终公开声明(第44、46、67章);发现"第三只手"首簇试火、地球"灰烬层"、守望者苏醒三者精确同步于基地纪元498年,记录为全书悬而未决的核心谜题(第74章);在第75章"系结"一章中首次将四条主线并置,提出全书主题总纲。亲赴中立星域,与凯登、崔维兹、守望者(米拉远程连线)首次五方同桌核对"498年"线索,促成全银河公开征集协查的联合声明,建立常设联合核查机制(第81-84章);与三年通信的凯登首次当面相见,获守望者赠予苔藓分株并被称为"第二个真正信得过的人"(第82、85章)。在端点星大学设立"观念动力学常设研究所",章程强制写入两条反自我固化条款(每年公开《本年度被推翻的结论》、常设不承诺解答的"未解栏");收到一名26岁学者"谁来质疑您的谦虚"的质疑信后,将其全文公开并为其新设五年任期的常任驳议席,职责仅为"公开挑我的错";致信凯登时不给结论只给方法——"你不需要先确定自己是,你只需要在坐上去之前先给自己造一面回音壁"(第94章)。

### 德纳·卢金市长
